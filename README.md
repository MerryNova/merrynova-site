# MerryNova website starter

A responsive, static British-English affiliate discovery website. It is intentionally LEGO-focused at launch but designed so new product categories can be added later.

## Before publishing
1. Replace `hello@merrynova.example` with a real email address in `index.html` and `privacy.html`.
2. Add your own original editorial content and product guides.
3. Add affiliate links only after the relevant advertiser/network approves your account and supplies tracking URLs.
4. Update the privacy notice to match any analytics, forms, cookies, email tools or other services you add.
5. Do not use LEGO logos or imply official affiliation. This site includes a non-affiliation notice.

## Free publishing with GitHub Pages
1. Create/sign in to a free GitHub account at https://github.com.
2. Create a **public** repository named `merrynova-site` (or `<your-github-username>.github.io` for a user site).
3. Upload all files from this folder to the repository root (not the ZIP itself).
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**; select `main` and `/ (root)`, then Save.
6. Wait for the Pages deployment to finish. Your project URL will be `https://<your-github-username>.github.io/merrynova-site/` (or `https://<your-github-username>.github.io/` for a user site).
7. Open the URL on mobile and desktop to check it.

GitHub Pages is free for public repositories on GitHub Free. The final URL depends on your GitHub username and repository name; it cannot be known before you create them.

## Rakuten application notes
Use the live website URL only after deployment succeeds. Describe the site accurately as an independent gift-guide/editorial website focused initially on LEGO building-set and gift inspiration. Do not claim traffic you do not have; enter zero or the truthful range requested. Rakuten may review the site and individual advertisers have their own approval criteria.
